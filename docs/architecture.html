CoinClock · server architecture

五端客户端 · 价格行情与规则引擎 · 多渠道通知 · 权益/AI · 非托管交易适配 · 事件驱动数据面

数据面

行情按 instrument 分区进入事件日志；规则消费有序事件；Redis 只做加速，PostgreSQL 保存触发、账本和审计事实。

安全边界

客户端永不持有服务端密钥；交易采用钱包签名；API、WS、推送、管理和外部 RPC 均有独立身份与最小权限。

可演进

S0 只需启用提醒和通知；S1 加入 AI/权益；S2 加入非托管 DEX 适配；自建撮合和清算列为独立 S3。
