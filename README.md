本仓库当前交付的是**设计方案**，不是已实现系统的说明书。2026-09-21 检查工作目录时目录为空；“已完成单币种闹钟”来自需求描述，尚未核验代码。截图中的平台币、VIP、NFT、AI 分析师与 DEX 作为产品构想输入，未视为已确定的业务规则。

## 当前设计结论

- 首发闭环：多币种行情 → 云端规则判断 → 五端提醒 → 确认/暂停 → 历史与同步。
- 客户端：Flutter 覆盖 iOS / Android；React + TypeScript 覆盖 Web，Tauri 2 承载 Windows / macOS。
- 服务端：Java 21 LTS + Spring Boot、PostgreSQL、Redis、Kafka 兼容消息服务；先模块化服务与独立行情/规则/通知进程，按负载拆分。
- 交易阶段：先用非托管钱包对接现有 DEX；自建撮合、保证金、清算与链上结算列为独立后续工程，附目标架构及进入条件。
- 平台币和 NFT：先设计权益与支付适配层；发行链、经济模型、合约和分发规则未定，不作为闹钟上线依赖。

产品负责人仍需确认：现有代码位置、目标市场与首发地区、现有 DEX 接入还是直接自建、交易品类、平台币所在链、NFT 权益范围、AI 解锁是否包含随机抽取。文档已给出默认方案与相应变更影响。
